# 🗂️ Project Structure

The repository is organized into clearly separated folders based on SQL concepts and practical modules:

```id="structure01"
📁 DDLNotes              → CREATE, ALTER, DROP
📁 DMLNotes              → INSERT, UPDATE, DELETE
📁 select                → SELECT fundamentals
📁 where                 → Filtering using conditions
📁 orderby               → Sorting results
📁 groupby               → GROUP BY & Aggregations
📁 joins                 → INNER, LEFT, RIGHT, FULL JOIN
📁 sailorjoins           → Join practice problems
📁 subquery              → Nested & Correlated subqueries
📁 functions             → Built-in SQL functions
📁 comparisonfunction    → Comparison operators & functions
📁 string                → String manipulation functions
📁 datetime              → Date & Time functions
📁 constraints           → PK, FK, UNIQUE, NOT NULL
📁 foreignKey            → Foreign key implementation
📁 windowsfunction       → Window functions
📁 firstvalue            → FIRST_VALUE & LAST_VALUE
📁 practice-1            → SQL practice problems
📁 homework              → Additional exercises
```

Each folder contains structured examples, syntax explanations, and hands-on queries.
